# Payor-Specific Field Mapping Reference

## Anthem Blue Cross California

### Required Fields for Reauthorization

| Field | Description | Source Location in Progress Report |
|-------|-------------|-----------------------------------|
| Diagnosis Code(s) | ICD-10 codes (F84.0, F84.1, etc.) | Client demographics section |
| Authorization Period | Start and end dates | Header or administrative section |
| Supervising BCBA | Name and credential number | Header or signature block |
| Standardized Assessment | VB-MAPP, ABLLS-R, or Vineland-3 scores | Assessment section |
| Skill Acquisition Data | Targets with mastery criteria and progress | Skill acquisition/program data section |
| Behavior Reduction Data | Operational definitions, baselines, current data | Behavior reduction section |
| Hours Utilization | Authorized vs utilized by CPT code | Administrative/billing section |
| Treatment Goals | Measurable goals with status | Treatment plan section |
| Caregiver Training | Sessions, topics, parent skill acquisition | Caregiver training section |
| Discharge Criteria | Measurable criteria with benchmarks | Discharge plan section |
| Medical Necessity | Functional impairment, regression risk, ASD connection | Generated from clinical data |

### MCG Care Guidelines Key Requirements

1. **Functional impairment** must be documented across multiple domains
2. **Risk of regression** must be explicitly stated if services are reduced
3. **ASD core deficits** (communication, social interaction, restricted behaviors) must be connected to treatment goals
4. **Intensity justification** must reference severity-based clinical rationale
5. **Utilization below 80%** requires written explanation
6. **Discharge criteria** must be measurable with specific benchmarks

### Common Denial Reasons (Anthem CA)

- Missing or vague operational definitions for behavior targets
- No baseline data for behavior reduction targets
- Utilization below 80% without explanation
- Missing caregiver training documentation
- Non-measurable discharge criteria
- Assessment data older than 12 months
- Missing medical necessity justification
